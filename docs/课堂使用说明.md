# 课堂使用说明（一页）

> MONOFORM 课堂版 · 白模预演 → 机位图 → 视频提示词。打开 `启动白模工具.cmd` 或 `npm run dev` 后浏览器访问本机地址。

## 一、标准流程（五步）

1. **建布景**：左侧「资源库」拖入人物与家具；门/窗直接放，墙用「方块」拉高拉薄（厚 ≤0.35m、高 ≥1.8m 自动识别为墙）；给每个对象起有语义的名字（提示词和机位图都会引用它）。
2. **复制镜头**：左下「镜头」面板「新建镜头」复制当前布景——**每个镜头各存一份布景**，改第 2 镜不影响第 1 镜。
3. **顶视摆位**：右上「顶视」进入平面图视角（北朝上、米制网格、比例尺左下）。此时拖人物只走地面、旋转只转水平角；「图层面板」（右侧）可开关网格/标签/视锥/轴线/视线/路径/幽灵。
4. **打关键帧 + 查轴线**：时间轴上（方向键可逐帧移动）选中对象或主摄像机后点「角色状态关键帧 / 物体关键帧 / 镜头关键帧」。两人轴线自动生成（可在面板指定 A/B），机位越线时**视口顶部出橙色警告**——把机位拖回同一侧，或有意越轴就换景别拉开。
5. **复制提示词**：右侧「机位词」页签 → 卡片自动生成五层描述（含镜头运动）→ 填一句动作 → 点绿色「**复制生成版**」→ 连同你的人物参考图、场景参考图一起贴进豆包/即梦生成视频。左下「导出机位图」得一张白底 PNG 可交作业/打印。

## 二、正反打与越轴（30 秒版）

- 两人之间的连线就是**轴线**；机位要始终待在轴线的同一侧拍（正打 A、反打 B 都在同一侧），否则观众会觉得人物突然换边。
- 本工具在越线瞬间会把机位符号、视锥和标签牌全部变橙并弹顶部警告；看见橙色就回到绿的那一侧。
- 「幽灵机位」自动显示同场其它镜头的机位（灰色），用来检查各镜之间有没有互相越轴。

## 三、已知限制

- 没有专用墙段类型——墙是「拉高拉薄的方块」，识别规则见上；
- 每个镜头独立保存一份布景，改布景不会跨镜同步；
- 提示词的动作层需要人工填写（工具只算空间与镜头，不编表演）；
- 机位图/标注只在编辑视图出现，**不会**进入 PNG 截图与 MP4 成片。
