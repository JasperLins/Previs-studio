# MONOFORM 导演台 · 课堂预设工程（母版）

本目录存放可直接用 MONOFORM「打开工程」载入的课堂母版场景（`.monoform.json`）。
全部预设只使用 MONOFORM 内置类型（骨骼白模人物 + 方块 / 球体 / 圆柱 / 平面 / 桌 / 椅 / 门 / 窗 / 树 / 车 / 拱门 / 楼梯等程序化粗模）拼搭，
人物姿势全部来自自带姿势库，**不含任何外部 GLB 与贴图，文件自包含，换台电脑打开即用**。
配色统一为白 / 浅灰 / 米色系；书架、柜台、背景柜等内置没有的物件均由方块组合拼出体量示意。

## 使用规范（课堂必读）

1. **母版只读**：本目录文件是教学母版，不要直接在母版工程上做课堂练习。载入母版后，先在右侧「工程」面板把工程**另存 / 复制为自己的新工程**（或用「新建」后重新载入母版），再开始修改。
2. MONOFORM 打开 `.monoform.json` 后会把它注册进本机的工程库（IndexedDB），后续编辑保存在工程库里、不会写回 json 文件；但仍以「副本工程」进行修改，避免课堂结束时的工程混淆。
3. 预设文件为 `version 16` 工程结构：各镜头共用顶层 `objects`（布景与人物位），每个镜头只带自己的 `camera`；载入后每个镜头可独立摆布景。
4. 镜头命名保持「镜头 01、02、03…」序号规范（预设 02 的 A/B/C 机位命名是轴线教学专用，见下）。
5. 需要新道具时，继续用「添加物体」里的内置粗模与方块拼搭，不要导入外部模型，保持课堂文件可互通。
6. **内置预设库**：内置预设入口在右侧「项目」面板的「课堂预设」分组，任何浏览器打开应用即可一键「载入」（无需手动选文件）；数据源即本目录的 json 文件，修改本目录后需重新构建（`npm run build`）才会生效。

## 各预设布景速查

- **01 雨夜书店**：封闭房间 12×10m，后墙两组书架（方块拼装），左前柜台（基座+柜身+台面），临街墙两窗一正门，读者桌椅两组；冷色夜景灯光。
- **02 双人对话**：三面墙（+Z 机位侧开放），1 桌 2 对坐椅，后墙 1 门 + 右墙 1 窗 + 背景柜；轴线 = 两人连线（X 轴），A/B 机位在轴线同侧（+Z），C 机位在对侧（-Z）。
- **03 透视纵深街道**：车道 + 两侧人行道，左右各 4 间店面粗模（近处带店门/橱窗细节），左路缘 4 盏等距路灯（z=-2/-12/-22/-32），右侧 3 棵行道树，远处 3 栋高楼收一点透视灭点。

## 技术说明

- 工程结构以 `src/App.jsx` 的 `normalizeProjectData`（PROJECT_VERSION 16）为准：`settings / activeShotId / objects / camera / lighting / shots[]`，镜头 camera 用 `position + target` 表达（载入时自动换算朝向）。
- 预设 01 使用冷色低照度灯光模拟雨夜；02/03 使用默认暖光。雨夜氛围为灯光数据，不依赖任何特效资源。
