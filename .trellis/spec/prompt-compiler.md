# 提示词编译规格

> 纯函数模块：输入 = 适配层给出的镜头数据模型（场景对象 + 机位 + diagram 扩展），输出 = 分层提示词文本。禁止依赖 UI 状态；禁止生成动作/表演内容。

## 1. 计算管线

1. 取当前 shot 的 objects 与 camera。
2. 建机位坐标系：由 camera.position/rotation 求视线方向与右向向量；画幅由 aspectRatio 解析宽高比；焦距 → 水平/垂直视场角（全画幅口径：水平 2·arctan(18/f)，垂直 2·arctan(12/f)，再按画幅裁切校正，以实现时统一的公式为准并写入单测）。
3. 对每个对象做投影：变换到机位坐标系 → 判定在画内/外 → 画内求屏幕横向落点（归一化 0–1）与深度 → 按下表映射为措辞。
4. 人物补充：朝向相对镜头的分档、两人相对关系（距离、谁在谁的哪侧、视线关系）。
5. 按第 3 节模板拼装；场景层只列入画对象，按深度由近及远。

## 2. 术语映射表（定版，改动需评审）

**画面横向（9 档）**：落点 x：<0 出画（左）｜0–0.08 左边缘｜0.08–0.25 左侧｜0.25–0.42 左中｜0.42–0.58 中央｜0.58–0.75 右中｜0.75–0.92 右侧｜0.92–1 右边缘｜>1 出画（右）。出画对象不进人物站位层（可在一致性层提示「X 在画外左侧」）。

**景深层（相对主体）**：设主体距离 d（拍摄对象，缺省取最近入画人物）。深度 < 0.6d → 前景；0.6d–1.4d → 中景；> 1.4d → 后景。

**朝向相对镜头（5 档）**：人物朝向与「人物→机位」方向的夹角 θ：θ≤30° 正面｜30–60° 四分之三侧面｜60–120° 侧面｜120–150° 四分之三背面｜>150° 背面。

**景别推断**：主体在画面中的高度占比 h（人物用身高投影估算；非人物主体用包围盒）：>0.8 特写｜0.5–0.8 近景｜0.3–0.5 中近景｜0.15–0.3 中景｜0.08–0.15 全景｜<0.08 远景。此值同时供机位标签牌使用；shotMeta.shotSizeOverride 非空时以覆盖为准。

**距离措辞**：输出「约 X 米」（一位小数）+ 最近地标锚点：取该人物 1.5m 内最近的建筑/家具对象名（如「站在门口左侧」——方位词由相对位置生成，拿不准时只给距离、不编方位）。

**视线关系成句**：两人均入画时判定：双方朝向互指（各自朝向与连线夹角均 <25°）→「两人对视」；一方指另一方、另一方不正对 →「A 看向 B」；有 gazeTarget 时优先按目标描述（「A 看向门口」）。

## 3. 输出模板

```
{景别}，{焦距}mm，镜头在{机位锚点：机位 1.5m 内最近地标，无则省略此短语}，朝{画面中心方向最近的地标/对象}拍摄；{画幅}画幅。
{逐人：名字 + 画面位置 + 景深层 + 朝向档 + 姿势词（由 pose 映射：站立/坐着/行走中…）}；{两人关系句：相对左右、距离、视线关系}。
{入画家具/建筑按深度由近及远列举名字，逗号分隔}。
{用户在面板填写的一句话，原样输出；未填则输出占位提示行「（待填写）」}
{左右关系复述}；机位在{轴线人物}轴线的{侧别}，不越轴。{上一镜存在时：与上一镜 S{n} 的差异点（如人物换位、机位侧别变化）逐条列出}
```

## 4. 测试用例（实现时写成单测/对照表，P2 验收逐例核对）

基线场景 = 课堂样例（房间：前台在北、左墙两窗、门在南侧中、桌椅在东；奶奶在西北、男主在西侧中部）：

1. 机位在门口朝北拍 → 男主应为「左前景、侧面」，奶奶「中后景偏左、正面或四分之三」，两人距离与图测一致。
2. 机位移到男主东侧正对他 → 男主「中央、正面、近景（按距离）」，奶奶出画或在后景，按实际投影。
3. 焦距 24→85 同机位复测：景别推断至少跨两档，视锥相关字段（编译器内部值）随之变化。
4. 把机位拖过两人轴线 → 一致性层侧别翻转，并出现越轴提示语义（与标注层警告一致）。
5. 奶奶设注视目标为「门」→ 视线句变为看向门口，不再写对视。
6. 只有一名人物入画 → 不生成两人关系句。
7. 动作层留空 → 输出占位行且其余层完整。
8. 非 16:9 画幅（9:16）复测用例 1：横向落点按竖幅重新计算，不许沿用横幅结果。
9. 人物背对镜头（θ>150°）→ 输出「背面」。
10. 导入 GLB 对象入画 → 场景层以对象 name 列举，不崩溃。

## 5. 禁止事项

- 不得用生成式 AI 改写/润色输出（编译必须是确定性的，同输入同输出）。
- 不得把出画对象写进入画描述；不得编造不存在的地标与方位。
- 距离、角度一律来自数据计算，禁止估算填空。
