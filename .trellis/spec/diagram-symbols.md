# 符号体系规格（顶视图）

> 对标 Hollywood Camera Work《Shot Designer》符号系统 + 建筑制图惯例。原则：抽象、统一、信息靠标签；全部矢量；实现为顶视时的替换渲染/叠加层（SVG 或 three 线/面，T02/T04 时定，但视觉结果以本文件为准）。

## 通用规则

- 线宽（100% 缩放基准）：轮廓 2px、结构线 1px；随缩放等比。
- 配色：底图黑/深灰线；机位高饱和绿 `#22c55e` 系；选中态描边用主题强调色；警告橙 `#f97316`；视线蓝虚线；路径黑细线；幽灵对象 40% 透明灰。
- 标签字体：系统无衬线（PingFang / Microsoft YaHei / sans-serif），字号不小于 11px（100% 时），禁止手写风。
- 尺寸口径：家具/建筑按对象 scale 的 X/Z 足迹真实比例绘制；人物与机位符号为固定图面尺寸（直径/边长按下方数值，±20% 可调），另带小圆足迹表示占地。
- 每个符号必须带可开关的文字标签（对象 name），人物与机位默认开，家具默认关。

## 人物（type=person）

- 主符号：圆环（外径 34px）+ 圆心头点（实心，直径 10px）+ 圆周朝向刻度（长 8px 的短线，位于朝向方向）。圆环描边色 = 对象 color；头点深灰 `#333`；刻度同描边色。
- 朝向：刻度方向 = rotation 的水平角，与 3D 模型面朝方向严格一致（T04 验收逐一核对，这是最易错点）。
- 姿势变体（由 pose 字段映射）：站立类 → 标准圆；坐姿类（sit 等）→ 圆 + 朝向侧一道短弧（表示座面）；蹲姿类 → 圆缩小至 26px + 内点；行走/奔跑 → 圆 + 身后 14px 虚线尾迹。未映射姿势 → 标准圆 + 姿势名小字标签。
- 名称标签：圆的下方 4px，居中，如「奶奶」。

## 机位（camera）

- 主符号：绿色机身矩形（22×14px）+ 朝向侧镜头楔形（等腰梯形，长 10px），楔形指向 = 拍摄方向（由 camera.rotation 水平分量决定）。
- 视角锥：浅绿半透明扇形（填充透明度 0.12、边线 0.5），角度/长度规则见 product-spec 第 2 节。
- 标签牌：深蓝底（`#1e3a8a`）白字圆角矩形（圆角 4px，内边距 4×8px），置于机位符号旁（默认右上，避让画布边缘自动翻转），三行内：`Cam A`/`中景 · 奶奶`/`35mm`。
- 当前镜头机位为实色可编辑；其他镜头机位为幽灵样式（见 product-spec）且标签只显示镜头名。

## 家具与建筑（按 type）

| type | 画法 |
|---|---|
| table | 足迹矩形 + 内缩 3px 内框线 |
| chair | 足迹矩形 + 靠背侧一条加粗线（靠背方向由 rotation 决定，取模型本地 -Z 侧，T04 核对） |
| sofa | 足迹矩形 + 靠背粗线 + 两侧扶手短线 |
| stairs | 足迹矩形 + 沿长度方向的踏步平行线（间距按 scale 均分 6–10 级）+ 上行箭头（方向由 rotation 决定） |
| door | **符号替换**：在足迹位置画门板线（长 = 足迹宽）+ 90° 开启弧（铰链侧由 rotation 决定）；原模型顶视隐藏 |
| window | **符号替换**：足迹位置画三线（两条外框线 + 一条中线，间距均分足迹厚） |
| box（薄高：厚 ≤0.35m 且高 ≥1.8m） | **按墙画**：双线 + 两端收口；其余 box 按普通足迹矩形 + 对角点线 |
| arch | 两端柱点（小方）+ 跨线 |
| roof | 足迹矩形虚线 + 对角线 |
| tree | 圆冠轮廓（直径 = 足迹宽）+ 圆心点 |
| vehicle | 足迹矩形圆角 + 车头侧短刻度（由 rotation 决定） |
| sphere / cylinder | 足迹圆轮廓 |
| plane | 足迹矩形虚线边 |
| assembly | 整体足迹矩形 + 名称标签（内部 parts 不展开） |
| model（导入 GLB） | 足迹包围框（由模型包围盒 X/Z 决定）+ 通用标记 + 名称标签 |
| depthMesh | 足迹包围框 + 斜线填充 + 名称标签 |

## 标注层符号

- 轴线：两人连线，灰色虚线（6/4），两端各延长 1m；安全侧在图层开启时以极浅色半平面提示（可选，P1 评估）。
- 视线：蓝色虚线（4/4），从人物符号边缘发出；有目标时止于目标边缘，无目标长 1.2m。
- 路径：黑色细线 1.5px，节点为小圆点 + 序号（白字深底小圆），末端实心箭头。
- 警告态：越轴时机位符号描边与标签牌底色变橙，视锥填充变橙系半透明。
