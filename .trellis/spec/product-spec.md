# 产品规格（开发版）

> 决策来源：《2.5D模式产品规格-讨论稿.md》v0.3。本文件是开发定版，只写做什么与怎么验；背景与取舍看讨论稿和 00-overview。

## 1. 功能范围

在 MONOFORM 既有 3D 预演之上增加：

1. **顶视正交编辑视图**：一键进入/退出；进入时编辑相机置于场景正上方、正交投影；视口背景切浅色图纸底；网格为米制（1m 主格、0.5m 次格可开关）；方向标与比例尺显示。
2. **地面约束编辑**：顶视下拖拽对象只改 X/Z（高度锁死）、改朝向只改水平角；复用既有变换控制器与吸附、撤销栈；与 3D 视图共用同一选中状态。
3. **Gizmo 标注层**（全部编辑层渲染，不进成片导出；逐项可开关）：机位视锥与标签牌、轴线与越轴警告、视线、走位/机位路径、幽灵机位。
4. **顶视符号替换**：人物、门、窗、墙（薄高 box）在顶视下按 diagram-symbols.md 渲染为专业符号；其余对象沿用模型顶面 + 描边；离开顶视自动恢复。
5. **提示词编译**（P2）：选中机位生成分层提示词（见 prompt-compiler.md），面板内可复制、可导出 TXT；动作层为用户输入框。
6. **机位图导出**（P2 可选）：状态 → 白底机位图 PNG（符号+标签+图例），供交作业/打印。

## 2. 关键行为定义

- 视图切换不改变任何场景数据；切镜时所有标注与符号跟随当前 shot 刷新。
- 视角锥：半透明扇形，角度由 focalLength 换算水平视场角（全画幅口径 2·arctan(18/f)），锥长 = 到最远入画主体距离 + 1m（图层设置可切固定 5m）。
- 机位标签牌：深蓝底白字，内容 `Cam {字母}` / 景别 / 拍摄对象名 / `{focalLength}mm`。景别自动推断（prompt-compiler 8.2 同一算法），可在 shotMeta 手动覆盖。
- 轴线：由 diagram.axisPair 指定两个人物的连线（默认前两名人物）；机位越线时标签与视锥变橙，视口顶部出现文字警告；判定用机位与轴线两端点的位置关系（叉积符号），拖动中实时计算。
- 视线：人物朝向发出虚线；设了注视目标（对象或点）则连到目标。数据存 diagram.gazeTargets。
- 路径：同一对象跨关键帧的位置连成细线，节点编号为关键帧序，末端箭头；人物与机位各一条。
- 幽灵机位：同场其他镜头的机位以灰色半透明符号 + 小标签（镜头名）显示，不可拖、不可选；数据由各 shot 快照的 camera 抽取，不另存。
- 符号替换的判定：当前编辑相机为顶视正交时启用；判定逻辑集中在一个开关函数内，禁止散落各渲染分支。

## 3. 数据（diagram 扩展区）

工程 JSON 顶层新增可选 `diagram` 对象，缺省值在 normalize 时补齐；原版 MONOFORM 打开带 diagram 的工程不得报错（P0 必测）：

```jsonc
"diagram": {
  "axisPair": ["actorId1", "actorId2"],        // 可为 null
  "gazeTargets": { "actorId": {"objectId": "x"} /* 或 {"point":[x,z]} */ },
  "layers": { "grid": true, "labels": true, "frustum": true, "axis": true, "sight": true, "paths": true, "ghosts": true },
  "shotMeta": { "shotId": { "camLetter": "A", "shotSizeOverride": null, "subjectId": "actorId" } },
  "promptDrafts": { "shotId": { "actionLine": "" } }   // 动作层草稿随工程保存
}
```

幽灵机位不落盘（从 shots 实时抽取）。除以上字段，禁止再往工程里加我们的字段；确需新增，先改本文件并评审。

## 4. 验收总纲（细则在各任务文件）

1. 顶视下全部既有 type 均有正确呈现（符号或顶面），朝向与 3D 一致（抽 10 对象核对）。
2. 焦距 18→120mm，视锥角度与公式误差 <1°，标签同步。
3. 顶视拖动后切回 3D，位置/朝向一致、无高度漂移；撤销可回退。
4. 机位拖过轴线，警告实时出现/消失。
5. 提示词与俯视/机位监看逐项核对，测试用例 10 例全对（prompt-compiler.md）。
6. 无 diagram 字段的老工程正常打开；带 diagram 的工程被原版打开不报错。
