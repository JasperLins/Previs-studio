# 层级双击重命名与机位词同步 + 滑块数值手动输入

## Goal

提升属性编辑效率：场景层级支持双击就地重命名，并保证改名后所有镜头的机位词同步；属性面板所有滑块的数值支持手动键入，非法输入自动还原。

## Requirements

### R1 场景层级双击重命名 + 机位词同步

- R1.1 「场景层级」列表中的物体行支持双击进入行内编辑名称；Enter 或失焦提交，Esc 取消；提交空值（含纯空白）时回退为原名。
- R1.2 编辑态不触发行选中（事件 stopPropagation）；锁定/隐藏按钮行为不受影响。
- R1.3 名称长度上限 30 字符（与镜头重命名一致）。
- R1.4 主摄像机行（哨兵 `CAMERA_ID`）不可重命名。
- R1.5 提交改名后，名称同步到：全局 `objects`、所有镜头的 `shot.objects` 快照（按 `object.id` 匹配扇出）。语义：同一 id 为同一实体，名称是项目级属性。
- R1.6 机位词为实时派生数据（`compileShot` 纯函数），激活镜头的机位词随 R1.5 自动重算；非激活镜头快照被 R1.5 扇出覆盖，切换镜头后名称保持新值，跨镜头一致性层（`prevShot.objects`）同样显示新名。
- R1.7 撤销历史按提交合并（一次提交一条记录，沿用现有 280ms 防抖快照机制即可，无需新代码）。

### R2 滑块数值手动输入（非法自动还原）

- R2.1 `AxisSlider`（位置/旋转/缩放/关节各轴）右侧数值从只读 `<output>` 改为可输入控件；焦距、动作相位两处独立 `.range-field` 滑块同步支持。
- R2.2 编辑过程中不做强制校验/格式化（允许 "-"、"1." 等中间态）；blur 或 Enter 时判定：
  - 解析失败或为空 → 还原为滑块当前值；
  - 超出滑块当前轨道范围（名义 [min, max]；当前值越界时轨道已扩展至包含当前值，输入校验同步采用扩展后边界）→ 还原为滑块当前值（用户确认：还原而非 clamp）；
  - 合法 → 对齐到 step 网格（`Math.round(v/step)*step`，容忍浮点误差）后写入。
- R2.3 Esc 放弃编辑并还原。
- R2.4 单位与换算保持现状：旋转显示/输入角度、存储弧度；动作相位显示/输入百分比、存储 0-1；焦距整数 mm；其余按 step 决定小数位。
- R2.5 滑块禁用态（物体锁定、缩放轴锁定）时输入控件同样禁用；缩放等比逻辑对键入值同样生效（比例联动）。
- R2.6 不改变任何数据模型、存储格式与 `PROJECT_VERSION`。

## Out of Scope

- `promptDrafts.actionLine` 等用户手写文本中的旧名引用不做自动替换。
- 已导出的 SVG/PNG 机位图为落盘快照，不做追溯更新。
- 主摄像机重命名。

## Acceptance Criteria

- [x] 双击层级行出现行内输入框，Enter/blur 提交、Esc 取消、空值回退，长度上限 30。
- [x] 改名后：属性面板顶部名称输入框同步新名；当前镜头机位词中所有引用该物体的短语（机位锚点、朝向主体、站位、关系、场景层、轴线提示）立即更新。
- [x] 新建/切换到其它镜头再切回，名称保持新值；含该物体的镜头其机位词一致性层显示新名。
- [x] 所有滑块（位置/旋转/缩放/焦距/动作相位/关节）数值可键入：合法值生效且滑块跟随；非法/超范围/空输入还原为原值；Esc 还原。
- [x] 旋转键入 -90 提交后显示 -90°（内部弧度正确）；动作相位键入 50 提交后显示 50%；缩放等比开启时键入单轴值其余轴按比例联动。
- [x] `npm run build` 通过；`git diff` 不含与本功能无关的改动。
