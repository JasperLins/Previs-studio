# T07 · 机位图导出与课堂发布

**目标**：产出可交作业的干净机位图，并完成第一个课堂可用版本 class-v1。
**依赖**：T05、T06。**期次**：P2 收尾。

## 范围

1. 先评估：顶视截图（隐藏界面元素后）是否已达讲义级；不够才实现只读导出渲染 `src/diagram/exportDiagram`（状态 → SVG → PNG：白底、符号、标签、图例、比例尺、镜头名标题）。评估结论记录在本文件末尾。
2. 导出命名规范：`{工程名}_{镜头名}_机位图.png`，与提示词 TXT、成片编号一致。
3. 写课堂版使用说明（一页）：先定布景再复制镜头、顶视操作、正反打与越轴、复制提示词的流程、已知限制（无墙段类型、每镜一份布景）。
4. 跑 fork-discipline 回归清单全项；在 class 分支打标 `class-v1`，更新 PATCHES.md 基线与同步记录。

## 验收

- [ ] 机位图 PNG 白底干净、无界面元素，打印 A4 可读
- [ ] 使用说明经一名零基础者试读可照做（或教师代验并记录）
- [ ] 回归清单全过，class-v1 标签就位
