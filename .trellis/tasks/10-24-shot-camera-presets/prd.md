# 选中物体新建镜头时机位预设

## Goal

当用户在场景层级中选中某个物体（人物或几何体）后点击「新建镜头」时，弹出一个「添加机位」预设面板（参考设计稿图 1）；用户选择预设后，新镜头的场景照旧复制，但摄像机直接预设到一个对准该物体、符合该预设构图（方位/俯仰/距离/焦距/倾角）的位置。未选中物体（或选中的是主摄像机）时，保持现状：点击「新建镜头」直接复制当前场景与当前摄像机。

## Background

- 现状：`ShotsPanel` 的「新建镜头」按钮（`onAdd` → `App.jsx addShot()`）无条件复制当前场景 + 当前摄像机，用户需要手动摆机位。
- 设计稿（图 1）给出的「添加机位」面板是一个两列网格按钮组，预设包含：当前视角、正面特写、侧面跟拍、背面中景、45°俯拍、低角度广角、过肩镜头（左/右）、荷兰角、正面中景、正面全景、侧面近景、俯拍全景、低角度仰拍、鸟瞰。
- 本任务只做「新建镜头」时的机位预设；不改动已有镜头的摄像机，不涉及关键帧。

## Requirements

### R1 预设面板触发

- 点击「新建镜头」时，若当前 `selectedId` 对应一个场景物体（非主摄像机、物体存在且非隐藏锁定状态之外的特殊情况），先弹出「添加机位」预设面板，不立即创建镜头。
- 未选中物体 / 选中主摄像机时：保持现状，直接新建镜头（不弹面板）。
- 面板可取消（关闭按钮 / 点击遮罩），取消则不创建任何镜头，不产生任何状态变更。

### R2 预设集合

面板以两列网格展示以下预设（含简短构图说明，中文）：

1. 当前视角 — 沿用当前摄像机（与旧行为一致）
2. 正面特写 / 正面中景 / 正面全景 — 物体正前方，三种距离景别
3. 侧面跟拍 / 侧面近景 — 物体正侧方
4. 背面中景 — 物体正后方
5. 45°俯拍 — 前方 45° 仰俯角俯拍
6. 俯拍全景 / 鸟瞰 — 近垂直向下
7. 低角度仰拍 / 低角度广角 — 低机位仰拍，广角更夸张（更广焦距）
8. 荷兰角 — 前侧方 + 画面倾斜（roll）
9. 过肩镜头 / 过肩镜头（右） — 越过物体肩部看向其朝向方向

### R3 相机计算

- 每个预设基于选中物体的「视觉中心 + 包围尺寸 + 朝向（rotation.y）」计算机位：
  - 人物身高按体型系数（standard 1.0 / tall 1.14 / broad 1.03 / female 0.98 / male 1.06）× `scale[1]` 估算，基准约 1.8m。
  - 几何体按 `scale` 三轴即包围盒尺寸估算（与现有场景语义一致：box 的 scale 就是米制尺寸）。
  - 「正面」定义为物体自身朝向（`rotation[1]`）的前方（+Z 旋转后方向），保证旋转过的物体依然拍「正脸」。
- 构图距离按焦距对应垂直视场角 + 景别留白系数计算，保证物体完整入画（带边距）。
- 相机 rotation 复用 `cameraRotationToward(position, target)`；荷兰角等需要 roll 的预设直接写 `rotation[2]`。
- 面向对象属性只读：不修改物体，只生成新镜头的 `camera`。

### R4 新建镜头行为

- 选预设后创建新镜头：场景、光照、时长、循环等照旧从当前状态复制（含现有缩略图逻辑），仅 `camera` 替换为预设机位（「当前视角」则等于旧 `addShot` 行为）；`aspectRatio` 保持当前值不变。
- 面板中展示目标物体名称，让用户明确「机位将对准谁」。
- 创建成功 toast 提示包含镜头名与所选预设名。

## Non-Goals

- 不做预设的自定义/保存/管理。
- 不做机位预览（选预设前实时预览取景）；选中预设立即创建。
- 不修改已有镜头的摄像机或关键帧系统。
- 不做「过肩」的第二主体自动识别；过肩预设以选中物体自身朝向为视线方向。

## Acceptance Criteria

- [ ] 选中一个人物或几何体 → 点「新建镜头」→ 弹出「添加机位」面板，显示物体名与预设网格。
- [ ] 未选中物体/选中主摄像机 → 点「新建镜头」→ 与现状一致直接新建，无面板。
- [ ] 面板取消（遮罩/关闭）→ 不新建镜头、无 toast、场景状态不变。
- [ ] 任选一个预设（如 45°俯拍）→ 新镜头创建并激活，主摄像机监视器中该物体完整入画且构图符合预设（方位/高度/焦距/roll）。
- [ ] 「当前视角」预设 → 新镜头相机与旧 `addShot` 行为完全一致。
- [ ] 旋转过的物体（rotation.y ≠ 0）：「正面」系列机位出现在物体自身正前方。
- [ ] `node --test src/shotPresets.test.js` 全绿；`npm run build` 成功。
- [ ] 镜头上限（30）与去重命名等既有规则不受影响。
